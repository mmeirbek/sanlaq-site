# SAÑLAQ — лендинг

Пиксельный сайт-презентация для игры SAÑLAQ (казахская историческая пиксель-RPG).
Структура и механика по мотивам nodeck.online: полноэкранные слайды, переход с названием слайда,
кнопки Назад / Меню / Далее, звук и музыка. Три языка: қазақша (основной), русский, English.

## Запуск

Сборка не нужна — это статический сайт.

```bash
python3 -m http.server 8000
# открыть http://localhost:8000
```

## Структура

| Файл | Что внутри |
| --- | --- |
| `index.html` | Все 16 слайдов. Казахский текст написан прямо в разметке |
| `assets/js/i18n.js` | Русский и английский переводы + динамические тексты (костёр, одежда, названия слайдов) |
| `assets/js/main.js` | Движок слайдов, пиксельный переход, меню, свайпы/колесо/клавиши, интерактив слайдов |
| `assets/js/audio.js` | Звук: порт `ProceduralAudio.cs` из игры — домбра (Karplus-Strong) на пентатонике, ветер, эффекты |
| `assets/css/style.css` | Стили. На десктопе каждый слайд — сцена 1440×800, которая масштабируется под экран; на телефоне — колонка с прокруткой |
| `assets/img/` | Арт из игры: фон, карточки героев, скриншоты, портреты, иконки, спрайты, сцены, фото команды |

## Что поменять перед публикацией

- **Контакты.** В начале `assets/js/main.js` есть объект `CONTACTS` (Telegram, WhatsApp, Instagram, email).
  Пока он пустой, окно «Байланыс» показывает «контакты скоро появятся».
- **Тексты.** Казахский — в `index.html` (атрибуты `data-i18n`), русский и английский — в `assets/js/i18n.js` под тем же ключом.

## Управление

`←` `→` / Пробел / колесо мыши — между слайдами, `Home` / `End` — первый/последний, `M` — меню слайдов.
На телефоне — свайп влево/вправо. Адрес слайда в ссылке: `#/5`.

Settings → Pages → Deploy from a branch → `main` / `(root)`.
